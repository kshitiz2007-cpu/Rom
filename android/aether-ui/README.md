# Aether UI Android prototype

A lightweight non-root launcher/theme-engine prototype for Android. This lives under `android/aether-ui` to keep the repository's existing web/worker projects untouched.

## Build
Open this folder in Android Studio (or open the repository and select this Gradle project), sync, and run the `app` module. Choose Aether UI as the Home app in Android's Home app settings.

## v0.1
- Launcher intent entry
- Home screen + installed-app drawer
- Four color presets (Aurora, Mint, Rose, Solar)
- Compose UI theme foundation

This is a third-party launcher; it cannot replace Samsung SystemUI, Settings, or the lockscreen.
